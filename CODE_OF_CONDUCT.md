# Code of conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] in full.
The canonical text lives at that link rather than being copied here, so it
cannot drift from the version we actually adopted.

In short: be respectful, assume good faith, and keep disagreement about the work
rather than about the person. Technical disagreement is welcome and expected.
This project's whole subject is refusing to answer questions that cannot be
answered correctly; the same directness applies in review, and it is not rudeness.

## Reporting

Report unacceptable behaviour privately to the maintainers through
[GitHub Security Advisories][report], which is private, or by opening an issue
if the matter is not sensitive. Reports are handled confidentially.

Enforcement follows the Contributor Covenant's guidelines: correction, warning,
temporary ban, permanent ban, according to severity and repetition.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[report]: https://github.com/rk-chavali/truegrain/security/advisories/new
